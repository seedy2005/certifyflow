# Security policy

CertifyFlow processes participant names and certificate files. Do not include real participant data in public reports.

## Reporting a vulnerability

Use GitHub's private vulnerability reporting for this repository (Security tab, then **Report a vulnerability**). Do not disclose suspected vulnerabilities in public issues or pull requests. Include the affected version, impact, and reproduction steps using synthetic data. The maintainer will coordinate a fix and disclosure timeline with the reporter.

The latest release and default branch are supported.

## Deployment

Each deployment is for one organizer. Keep the data directory private, use HTTPS, set unique credentials and a random session secret, and keep the application and dependencies updated.
